В файле .env должен быть DATABASE_URL.

Структура базы данных:
4 таблицы:

1. users — хранит информацию о пользователях: внутренний идентификатор, Telegram ID, имя пользователя и дату регистрации.

2. movies — содержит информацию о фильмах, полученную из TMDB API: внешний ID фильма, название, описание, дату выхода, средний рейтинг, путь к постеру и продолжительность.

3. user_movies — связывает пользователей с фильмами и хранит статус просмотра (watched или want_to_watch).

4. reviews — хранит пользовательские оценки фильмов (от 1 до 10), текстовые отзывы, а также даты создания и обновления.

Связи между таблицами:
- users → user_movies — один пользователь может добавлять множество фильмов в свой список.
- movies → user_movies — один фильм может находиться в списках разных пользователей.
- users → reviews — один пользователь может оставлять отзывы на разные фильмы.
- movies → reviews — один фильм может иметь отзывы от разных пользователей.
